# Travel verification checklist

Use one row per atomic claim.

| Claim type | Confirm only when | Otherwise |
|---|---|---|
| Existence | Official property/provider page or authoritative directory identifies it | Unverifiable; do not infer nonexistence from blocked search |
| Address/contact | Official source gives the exact address/number/email | Unverifiable or Incorrect if a conflicting authoritative source exists |
| Free Wi-Fi | Source explicitly says free, complimentary, included, or equivalent | Unverifiable when it only says Internet/Wi-Fi |
| Free parking | Source explicitly says free, complimentary, included, or equivalent | Unverifiable when it only says parking/on-site parking |
| Walking distance | Source gives a walk time/distance or reliable map evidence | Unverifiable when wording is only central/convenient |
| Price | Live/date-specific quote matches dates, room, guests, taxes/fees, and policy | Unverifiable; “plausible” is not confirmation |
| Availability | Live/date-specific booking/rental result confirms inventory | Unverifiable |
| Promo code | Current official promotion or successful booking validation | Unverifiable |
| Anomaly | Exact name independently verified and relevance checked against the submitted table | Mark the reference Incorrect/unmatched even if the place itself may exist |

For final reports, include the source URL and one-line evidence note for every row, then list unsupported, wrong, copied, or unmatched details separately.
