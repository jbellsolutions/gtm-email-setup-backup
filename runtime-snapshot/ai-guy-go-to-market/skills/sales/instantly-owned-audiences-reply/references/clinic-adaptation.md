# Adapting the Plan for Medical/Wellness Clinics

Campaign 3617053 sends niche-personalized cold emails. Some leads receive the standard coaching/consulting pitch; others (hormone clinics, wellness centers, med-spas) receive a referral-partnership pitch ("gyms, BJJ academies, barbershops already full of your patients"). When a clinic lead replies positively, the owned-audiences plan template needs adaptation.

## What changes

| Element | Standard (Coaching) | Adapted (Clinic) |
|---------|--------------------|--------------------|
| Page 1 mechanism | "borrowed trust from coaches, communities, podcasts" | "borrowed trust from gyms, trainers, barbershops" |
| Page 1 table header | "Power Partners" | "Referral Partners" |
| Page 2 partner types | Coaches, consultants, adjacent service providers | Personal trainers, BJJ/martial arts academies, barbershops, chiropractors, CrossFit boxes, yoga studios, run clubs |
| Page 2 influencer types | Business/coaching creators, mindset podcasts | Fitness/health creators, hormone optimization YouTube, mom wellness influencers, veterans' health podcasts |
| SpeakerAgent | Same — always name it | Same |
| Locked reply template | Same — never edit bottom section | Same — never edit bottom section |

## What stays the same

- The 3-page structure (page 1 hook, page 2 proof, page 3 close)
- The locked reply email bottom template ("Power Partners, Influencers and Podcasts" — use verbatim even though the plan says "Referral Partners")
- Booking link, site link, sender persona rules
- Todd Brown mechanism-first framing
- Banned words list
- Build script and here.now hosting

## Research priorities for clinics

1. **Local fitness ecosystem** — gyms, personal trainers, CrossFit boxes, yoga/Pilates studios near their location
2. **BJJ/martial arts academies** — dense concentration of male clients 25–55 (prime TRT/hormone demographic)
3. **Barbershops** — 45-minute captive audience talking about appearance, energy, drive
4. **Complementary providers** — chiropractors, PTs, med spas that don't offer hormone therapy
5. **Special groups** — veterans' orgs (if clinic does Veterans Claims), run clubs, cycling groups

## Naming convention for plan entities

Use the same format as the coaching template: named entities must be researched this session and marked *(to confirm)* if single-sourced. Categories are fine — they still prove we know the niche. A clinic plan with 4-5 real names + 4-5 categories is better than 12 invented names.

## The `contact@` problem

Clinics often have `contact@` or `info@` as their primary email. These are shared inboxes — no individual decision maker. 100% of `info@` addresses on PR campaigns unsubscribed or went hostile. Still build the plan if they replied positively, but flag it for Justin so he knows there's no named person to follow up with.

## Example: TRU Wellness Charlotte (July 13, 2026)

Cold email was about referral partnerships for clinics. Plan adapted page 2 partners to:
- reBalance Fitness, Carbon Performance Charlotte, Inertia Fitness Co, Trifecta Athletics, Strength + Wellness Collective (real Charlotte businesses)
- BJJ academies, barbershops, chiropractors, CrossFit boxes, yoga studios (categories)

Result: 3-page plan, hosted at here.now, reply email sent. `contact@` address flagged.
