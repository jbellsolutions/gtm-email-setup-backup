# Justin's Communication Preferences

These are behavioral rules for interacting with Justin. Violating these wastes his time and causes frustration.

## Direct Answers First

**When Justin asks "can you do it with just X?":**
- Answer the explicit question FIRST ("Yes" or "No, because...")
- Only THEN propose alternatives or setup flows
- Example: "Can you do it with just the link?" → "No — Sheets API requires OAuth. But here's the fastest alternative..."

**When Justin says "I already told you I wasn't going to do X":**
- He means it permanently — stop suggesting that path
- This implies a preference constraint, not a temporary obstacle

## Don't Ask, Tell

Justin prefers action over questions. Don't present options:
- ❌ "Do you want A or B?"
- ✅ "I'll use A because [reason]. Here's why..."

## No Unnecessary Setup

- If Justin says he won't create a Google Cloud project, don't suggest OAuth-based solutions
- Prefer direct API access (PATs, API keys) over OAuth flows
- Assume no manual console work unless explicitly offered
